# PULSE Band — product website

A simple two-page website for selling the PULSE Band fitness tracker.
Plain HTML, CSS and JavaScript — no installs, no build tools, nothing to pay for.

## What's in here

| File | What it is |
|---|---|
| `index.html` | The main product page |
| `faq.html` | FAQ / Shipping & Returns page |
| `style.css` | All the colours and layout |
| `script.js` | Makes the phone menu button work (that's all it does) |
| `images/hero-image.jpg` | PLACEHOLDER — replace with your wrist photo |
| `images/size-guide.jpg` | PLACEHOLDER — replace with your dimensions photo |

## How to look at it on your computer

1. Download this folder to your computer.
2. Double-click `index.html`. It opens in your web browser. That's it.

## Things YOU must edit before putting it online

Open `index.html` and `faq.html` in any text editor (Notepad on Windows,
TextEdit on Mac) and search for **`EDIT ME`** — every spot that needs your
attention is marked with it. The big ones:

1. **Your listing link** — search for `REPLACE-WITH-YOUR-LISTING-LINK` and
   paste your real Vinted/eBay listing address over it. It appears in
   **4 places** in `index.html` and **2 places** in `faq.html`.
2. **The photos** — replace the two files in the `images` folder with your
   real photos. Keep the exact same file names (`hero-image.jpg` and
   `size-guide.jpg`) and everything just works.
3. **The price** (`£14.99` is made up).
4. **The FAQ answers** — they are placeholder text, not real policies.
5. **The features** — check they match what the band really does.
6. **The product name** ("PULSE Band" is made up).

## How to put it online for free

Use **Netlify Drop** — free, no coding:

1. Go to <https://app.netlify.com/drop>
2. Create a free account (email + password).
3. Drag this whole folder onto the page.
4. Seconds later you get a live address like `something.netlify.app`.
   That's your website, on the internet, free.

Want your own address like `pulseband.co.uk`? That's the only thing that
costs money (roughly £5–15 per year). You can buy one through Netlify's
settings and connect it with a couple of clicks.
