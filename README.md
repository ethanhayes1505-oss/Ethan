# Shock Alarm Bracelet — Store Landing Page

A one-product landing page template (Fitsleeps-style layout, different colours) for a shock alarm bracelet. All product-specific content is left as clearly marked placeholders.

## What's inside

- `index.html` — the full landing page, self-contained (no external files needed). Open it in any browser to preview.

## Placeholders to fill in

Everything wrapped in `[square brackets]` needs your content:

- `[PRODUCT NAME]`, `[YOUR BRAND]`, prices `[£XX.XX]`, review counts `[X,XXX]`
- Dashed 📷 boxes = drop your product photos there
- FAQ answers, review quotes, and feature specs (battery life, intensity levels, etc.)

## Colour scheme

| Role | Colour |
|---|---|
| Dark sections | `#12151a` charcoal |
| Page background | `#faf7f2` warm off-white |
| Accent / buttons | `#ff6b2c` electric orange |
| Guarantee section | `#0e7c6b` teal |

All colours are defined once at the top of `index.html` in the `:root { }` block — change them there and the whole page updates.

## Using it with Shopify

Shopify doesn't accept a raw HTML file as a theme, so use one of these routes:

1. **Custom Liquid section (easiest):** In the Shopify theme editor, add a "Custom Liquid" section to your homepage and paste sections of this page into it (including the `<style>` block once).
2. **Rebuild in the theme editor:** Use this page as the visual blueprint — each section here (hero, how-it-works, features, comparison, reviews, guarantee, FAQ) maps to a standard section in free themes like Dawn or Sense.
3. **Page template:** Online Store → Pages → create a page, click the `<>` (show HTML) button in the editor, and paste the body content in.
