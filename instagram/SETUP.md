# SleepLabs Instagram: setup

## 1. Edit profile (Edit profile button)
| Field | What to put |
|---|---|
| Profile picture | `SleepLabs-profile-picture-1080.png` |
| Name | `SleepLabs · Silent Alarm Band` (this field is searchable, so "Silent Alarm" helps people find you) |
| Username | Currently `sleeplabs.s`. If it's free, change it to `sleeplabs.shop` so it matches your website |
| Bio | see below |
| Links | Add link → `https://sleeplabs.shop` |

**Bio** (copy exactly):
```
The vibrating alarm only the wearer feels.
Wake up. Let them sleep.
30-day returns ↓
```

## 2. Switch to a Business account (needed for ads)
Settings → Account type and tools → **Switch to professional account** → category **Product/service** → **Business**.
If it offers to connect a Facebook Page, choose **Sleeplabs**.

## 4. Don't
- Don't follow the suggested personal accounts.
- Don't add stars or "customer review" captions. These are brand posts, not reviews.
- Before going big on the "doesn't wake anyone" lines, do the quiet-bedroom test (same as for the ads).
